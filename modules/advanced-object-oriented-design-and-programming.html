Module Overview

Understanding Advanced Object-Oriented Design

This 12-week module develops the ability to design, implement and maintain secure, reusable and scalable software using advanced object-oriented principles. Topics include SOLID, creational, structural and behavioural patterns, concurrency, secure coding, refactoring, architecture, testing and dependency management.

The module also considers equality, diversity and inclusion, sustainability, entrepreneurship and responsible software engineering. The evidence on this page will be updated as activities and assessments are completed.

Critical Reflection

Reflective Learning Journal

My early work in this module has strengthened my understanding that object-oriented programming is not solely about organising code into classes. Design quality depends on separation of responsibilities, clear abstractions, extensibility and the ability to test software reliably.

The SOLID shopping-system exercise has provided a practical opportunity to examine tightly coupled designs and separate responsibilities. The Factory Method exercise has demonstrated how object creation can be delegated to specialised factories. In the thread-safe banking work, concurrency has raised additional questions about correctness when operations execute simultaneously, particularly the prevention of race conditions and deadlocks.

As the module progresses, I will critically evaluate the limitations of the approaches used, incorporate peer and tutor feedback, and update this reflection with evidence from Units 7–12. This is a developing reflection, not a final end-of-module submission.
