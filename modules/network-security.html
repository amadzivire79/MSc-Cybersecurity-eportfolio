MODULE OVERVIEW

Understanding Network Security

Network Security has developed my understanding of how computer networks can be protected against unauthorised access, exploitation, disruption and other cyber threats.

The module has provided an opportunity to connect theoretical cybersecurity concepts with practical technical activities. Through laboratory work and independent investigation, I have developed greater familiarity with network reconnaissance, vulnerability identification and security assessment.

My professional experience as a Fibre Optic Engineer has made the subject particularly relevant because secure communication networks depend on understanding both infrastructure and the security risks affecting connected systems.

Key Areas of Learning

  • Network architecture and security
  • Network threats and attacks
  • Network reconnaissance
  • Vulnerability assessment
  • Network scanning
  • Security controls
  • Secure network design
  • Risk and threat analysis

04 • REFLECTION

My Network Security Reflection

Network Security has significantly strengthened my understanding of the relationship between network infrastructure and cybersecurity. Before studying this area in greater depth, I primarily viewed network infrastructure from an operational and connectivity perspective. The module has encouraged me to consider the same infrastructure from the perspective of an attacker, defender and security professional.

Practical work with tools such as Nmap, Nessus Essentials and OpenVAS has helped me understand how security professionals gather information about networked systems and identify potential vulnerabilities. I have learned that the output of a security tool is not, by itself, a complete security assessment. Findings need to be interpreted, validated and considered within the context of the system and its associated risks.

One of the most valuable lessons has been the importance of distinguishing between identifying a vulnerability and understanding its actual business or operational impact. This has encouraged me to develop a more analytical approach when reviewing technical findings.

My experience as a Fibre Optic Engineer has provided useful context for this learning. Fibre infrastructure supports communication and connectivity, but secure network operation involves much more than the physical transmission medium. Devices, configuration, authentication, applications, users and management processes can all introduce security risks.

The module has therefore encouraged me to think more broadly about network security and resilience. It has also increased my interest in investigating security issues affecting last-mile telecommunications infrastructure.

How My Thinking Has Changed

I now approach network security problems more systematically by considering the assets involved, potential threats, vulnerabilities, likelihood, impact and available controls. I am also becoming more aware of the importance of combining technical controls with appropriate organisational processes and user awareness.

What I Will Do Differently

Going forward, I will place greater emphasis on documenting the reasoning behind technical findings rather than simply reporting scan results. I will also continue developing my practical skills in controlled environments while strengthening my understanding of established security frameworks and professional practices.
